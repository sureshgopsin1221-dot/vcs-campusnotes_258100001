# CampusNotes

A version control project for VCS Assignment 2.

## Purpose
Practice Git and GitHub workflows, including branching,
commits, forks, and pull requests.

## Getting Started
1. Clone the repository.
2. Navigate into the project directory.
3. Review the README before making changes.

## Project Overview
CampusNotes is a Git-based academic notes management project
developed for VCS Assignment-2.

## Features
- Organized lecture notes templates
- Version tracking using Git
- Collaboration through GitHub Pull Requests
- Contribution guidelines for team members

## Repository Structure
- README.md: Project documentation
- CONTRIBUTING.md: Contribution guidelines
- notes/: Lecture notes and templates

## Getting Started
1. Clone the repository from GitHub.
2. Open the CampusNotes project folder.
3. Create a feature branch before making changes.
4. Commit and push updates using Git.
