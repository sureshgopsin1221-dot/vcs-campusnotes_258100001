# Contributing to CampusNotes

## Getting Started

1. Fork the CampusNotes repository.

2. Clone your fork using:
   git clone https://github.com/YOUR_USERNAME/vcs-campusnotes_258100001.git

3. Create a feature branch:
   git switch -c feature/short-description

## Commit Message Guidelines

Use these prefixes:
- feat: New features
- fix: Bug fixes
- docs: Documentation updates
- refactor: Code restructuring
- chore: Maintenance

Example:
git commit -m "docs: improve contribution guidelines"

## Submitting Changes

1. Stage your changes using git add.
2. Commit with a descriptive message.
3. Push your feature branch to GitHub.
4. Open a pull request explaining the changes.
5. Address review feedback before merging.
